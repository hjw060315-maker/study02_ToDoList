# study02_ToDoList — 개인용 할 일 관리 앱

하루 10~20개의 할 일을 관리하는 개인용 웹 앱 프로젝트입니다. 브라우저에서 바로 실행되고, 새로고침해도 데이터가 유지되도록 순수 HTML/CSS/JavaScript로 만들 예정입니다.

## 주요 기능
- 할 일 추가 / 수정 / 삭제
- 완료 체크
- 카테고리 분류 (업무 / 개인 / 공부)
- 진행률 보기
- `localStorage`를 이용한 데이터 영속성
